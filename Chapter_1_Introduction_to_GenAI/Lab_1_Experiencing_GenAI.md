## Section 1: Text Generation

**Prompt:** Explain the architecture of a modern Large Language Model (LLM) — including tokenization, transformer blocks, attention mechanisms, and how autoregressive decoding produces coherent text. Compare decoder-only (GPT) vs. encoder-decoder (T5) architectures.

> **Result:** 1. The Core ArchitectureThe Transformer relies on the Attention Mechanism to understand the relationships between words, regardless of their distance in a sentence. It processes data through several key stages:  Tokenization: Raw text is broken down into smaller units called tokens (sub-words, characters, or words). Each token is converted into a numerical vector (embedding) that represents its semantic meaning in a high-dimensional space.  Positional Encoding: Since Transformers process all tokens in a sequence simultaneously (unlike older models that read left-to-right), they have no inherent sense of order. Positional encodings are added to token embeddings to inject information about the relative or absolute position of tokens in the sequence.  Transformer Blocks: These are the "layers" of the model. Each block typically contains:  Multi-Head Self-Attention: This allows the model to "focus" on different parts of the input sequence simultaneously, weighing the importance of each token relative to others.  Feed-Forward Networks: These process the information gathered by the attention mechanism, adding non-linearity to the model to learn complex patterns.  Residual Connections & Layer Normalization: These are structural techniques used to stabilize training, allowing for the stacking of many deep layers.  2. Autoregressive DecodingAutoregressive decoding is the mechanism by which LLMs produce coherent text. It operates as a step-by-step generative process:  Input: The model receives an initial prompt (or sequence of tokens).  Prediction: The model calculates a probability distribution over its entire vocabulary for the "next" token.  Selection: A token is sampled from this distribution (using strategies like temperature scaling or top-p/nucleus sampling).Iteration: The chosen token is appended to the input sequence, and the process repeats. This cycle continues until a "stop" token is generated or a length limit is reached.Causal Masking: During training, a mask is applied to the self-attention mechanism to ensure the model cannot "see" future tokens. This forces it to learn to predict the next word based only on previous context.  3.
